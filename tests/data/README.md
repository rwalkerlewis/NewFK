# Reference data for fkpy regression tests

## `canonical_zhu5.npz`

Frozen reference Green's functions for the canonical 5-layer continental
crust model in `canonical_zhu5.model`, generated by Lupei Zhu's Fortran
`fk` (the implementation that ships in
[`liuqinya/py_cap`](https://github.com/liuqinya/py_cap) under `fk/`).

To regenerate:

```bash
FK_SRC=/path/to/fk/source ./regenerate.sh
```

Run parameters:

- Source layer index 4 → source depth 30 km (top of the 4th layer).
- Receiver at the surface (layer 1).
- Source type: double couple (stype = 2).
- 6 distances: 50, 80, 100, 130, 160, 200 km.
- npts = 1024, dt = 0.1 s.
- σ = 2 cycles per trace, taper = 0.5, smooth = 1, no high-pass.
- p_min = 0, p_max = 1, dk = 0.3, k_max = 15.
- 25 samples reserved before the first arrival.

Stored arrays:

- `gf` — shape `(n_dist, 9, npts)`, float32, the 9 DC Green's-function
  components in Lupei Zhu's `fk` order (`Z0 R0 T0 Z1 R1 T1 Z2 R2 T2`).
  This corresponds to fkpy's `[DD_Z, DD_R, _, DS_Z, DS_R, DS_T,
  SS_Z, SS_R, SS_T]` after dropping the trivially-zero `T0` component.
- `distances_km`, `tfirst_s` — per-distance receiver distances and the
  user-supplied first-arrival times that fk used (these became the
  per-trace SAC `b` headers).
- Run parameters as scalar attributes.
